# PortSwigger: Web Security Academy

**PortSwigger** es la entidad desarrolladora de **Burp Suite**, el estándar de la industria para pruebas de seguridad web. A través de su **Web Security Academy**, proporcionan un marco de aprendizaje práctico y gratuito que cubre desde vulnerabilidades clásicas hasta vectores de ataque avanzados en entornos web modernos.

## 1. Ecosistema de Aprendizaje: Temas y Labs

El contenido se organiza por módulos de vulnerabilidades, cada uno vinculado a laboratorios interactivos:

* **Vulnerabilidades de Lógica y Entrada:**
* **SQL Injection (SQLi):** Desde el bypass de autenticación hasta la exfiltración de datos mediante técnicas *Blind*.
* **Cross-Site Scripting (XSS):** Vectores reflejados, almacenados y basados en DOM.
* **OS Command Injection:** Ejecución de comandos en el servidor a través de aplicaciones vulnerables.


* **Gestión de Sesiones y Control de Acceso:**
* **Broken Authentication:** Debilidades en mecanismos de login y tokens.
* **IDOR & Access Control:** Escalada de privilegios horizontal y vertical.


* **Vulnerabilidades de Lógica de Negocio:** Errores en el diseño de flujos de transacciones o procesos.

## 2. Infraestructura Técnica: Labs de Burp Suite

A diferencia de otras plataformas, PortSwigger utiliza laboratorios dinámicos integrados directamente con el navegador o su herramienta profesional:

* **Instancias Dinámicas:** Cada laboratorio genera una instancia única y temporal para el estudiante, accesible vía URL.
* **Interoperabilidad con Burp Suite:** Los laboratorios están diseñados para ser resueltos utilizando herramientas de interceptación, *Repeater*, *Intruder* y *Proxy*.
* **Niveles de Dificultad:** Clasificados en *APPRENTICE* (Principiante), *PRACTITIONER* (Profesional) y *EXPERT* (Avanzado).

## 3. Certificación: BSCP

PortSwigger ofrece una certificación de alto rigor basada estrictamente en el desempeño práctico:

* **Burp Suite Certified Practitioner (BSCP):** No es un examen teórico; es una prueba de 4 horas donde el candidato debe comprometer dos aplicaciones web reales, realizando el ciclo completo: desde el descubrimiento hasta el compromiso del servidor.

## 4. Metodología de Resolución

1. **Material de Lectura:** Teoría detallada sobre la vulnerabilidad.
2. **Laboratorio Guiado:** Escenarios prácticos con objetivos específicos.
3. **Soluciones y Comunidad:** Documentación oficial y discusiones técnicas para la resolución de problemas.
