 

# eMAPT Checklist: Domains & Objectives

| Dominio (Domain) | Objetivos de Control (Control Objectives) | Status |
| --- | --- | --- |
| **Mobile Malware Analysis** / Análisis de Malware Móvil | **[EN]** Evaluate real-world mobile APT campaigns. <br>

<br> **[ES]** Evaluar campañas reales de APT móvil. | [ ] |
|  | **[EN]** Analyze behavior (static/dynamic) and anti-analysis/evasion techniques. <br>

<br> **[ES]** Analizar comportamiento y técnicas de anti-análisis/evasión. | [ ] |
| **Reporting & Communication** / Reporte y Comunicación | **[EN]** Document vulnerabilities using OWASP MASVS, MTTG, and PTES. <br>

<br> **[ES]** Documentar vulnerabilidades usando OWASP MASVS, MTTG y PTES. | [ ] |
| **API & Backend Security** / Seguridad de API y Backend | **[EN]** MITM testing and bypass certificate pinning. <br>

<br> **[ES]** Pruebas MITM y bypass de certificate pinning. | [ ] |
|  | **[EN]** Identify undocumented endpoints; test for BOLA, BFLA, and token manipulation. <br>

<br> **[ES]** Identificar endpoints no documentados; probar BOLA, BFLA y manipulación de tokens. | [ ] |
| **Reconnaissance & Static Analysis** / Reconocimiento y Análisis Estático | **[EN]** Decompile APKs/IPAs to find hardcoded secrets and logic flaws. <br>

<br> **[ES]** Decompilar APKs/IPAs para hallar secretos y fallos lógicos. | [ ] |
|  | **[EN]** Extract and interpret app components (manifest/plist) and permissions. <br>

<br> **[ES]** Extraer e interpretar componentes (manifest/plist) y permisos. | [ ] |
| **Threat Modeling** / Modelado de Amenazas | **[EN]** Assess apps from an attacker's perspective. <br>

<br> **[ES]** Evaluar apps desde la perspectiva del atacante. | [ ] |
|  | **[EN]** Identify threat actors using PTES and OWASP MSTG. <br>

<br> **[ES]** Identificar actores de amenazas usando PTES y OWASP MSTG. | [ ] |
| **Security Foundations** / Fundamentos de Seguridad | **[EN]** Identify common vulnerabilities with real-world examples. <br>

<br> **[ES]** Identificar vulnerabilidades comunes con ejemplos reales. | [ ] |
|  | **[EN]** Explain architectural differences between Android and iOS impact. <br>

<br> **[ES]** Explicar el impacto de las diferencias arquitectónicas (Android vs iOS). | [ ] |
| **Dynamic Testing & Runtime** / Pruebas Dinámicas | **[EN]** Bypass SSL pinning, root/jailbreak detection, and anti-debugging. <br>

<br> **[ES]** Evadir SSL pinning, detección de root/jailbreak y anti-debugging. | [ ] |
|  | **[EN]** Observe behaviors in WebViews, IPC, and system logs. <br>

<br> **[ES]** Observar comportamientos en WebViews, IPC y logs del sistema. | [ ] |
|  | **[EN]** Hook and manipulate logic using Frida, Objection, or Xposed. <br>

<br> **[ES]** Manipular lógica mediante hooks con Frida, Objection o Xposed. | [ ] |
| **Reverse Engineering** / Ingeniería Inversa | **[EN]** Reverse engineer binaries (DEX, OAT, Mach-O) and defeat obfuscation. <br>

<br> **[ES]** Ingeniería inversa de binarios (DEX, OAT, Mach-O) y derrota de ofuscación. | [ ] |
